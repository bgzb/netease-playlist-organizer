# 0.1.0-preview.1 预览说明

这是首个公开预览，供愿意核对结果的 Apple Silicon Mac 用户试用。支持网易云 3.1.1 / build 3019；其他客户端、Intel 及全部 macOS 版本尚未验收。生产部署下限 macOS 13。

功能：读取完整“我喜欢”、扫描曲风/BPM/语种/歌手、按条件筛选、人工调整、审阅确认后写入一个新建私密或已有可写歌单，保留原收藏并读回核对；账号变化会撤销旧任务与确认。

应用仅 ad-hoc 签名，未 Apple 公证，首次打开参照 [安装说明](INSTALL.md)。使用密封应用 ZIP，不发布裸应用副本。包内版本为 0.1.0 / build 2，源码版本为 0.1.0-preview.1。

验证证据包括离线合成测试、实际入口合成冒烟测试、原生测试及同一台 Mac 的干净源码目录构建。用户曾亲自测试写入；不把合成测试或用户反馈等同于所有账号、规模及第二台 Mac 验收。GitHub CI 已配置，尚未运行。

已知问题：曾观察到冷启动断连，失败子条件尚未定位，不能声称修复；可手动重试。元数据可能缺失；客户端更新、登录、权限、限流或网络异常可能使操作暂停。现有图标后续再更新。

发布时应附应用 ZIP、已审阅源码 ZIP 与 SHA-256，并记录源码 ZIP 原提交和新公开仓库提交。当前文档不表示附件已公开发布。
