# 安装预览版

支持范围：Apple Silicon Mac，网易云 3.1.1 / build 3019。macOS 部署下限为 13；不同 macOS 版本尚未全面验证。正常使用无需 Node.js。

1. 下载发布附件“网易云歌单整理应用.zip”，解压，将 `.app` 移入 Applications 或用户应用目录。保留一个常用安装入口。
2. 首次尝试打开应用。预览版只有 ad-hoc 签名、未公证，macOS 可能阻止打开。
3. 确认下载来源并理解预览版限制后，打开“系统设置”→“隐私与安全性”，在安全性提示旁点“仍要打开”，按系统对话框再次确认。该按钮通常在尝试打开后约一小时内可用。
4. 同一应用获准后，通常可正常再次打开；换版本或换下载副本时，系统可能再次提示。

以上遵循 [Apple 官方说明：在 Mac 上安全地打开 App](https://support.apple.com/zh-cn/102445)。不要关闭 Gatekeeper、删除隔离属性或修改网易云应用。若系统报告恶意软件或文件损坏，不绕过警告，停止并核对下载及发布说明。

工具打开后由控制窗口引导加载面板；需要重新打开网易云时会请求用户确认，可能中断播放。使用完成先“恢复普通启动”，再退出工具。扫描和写入前请阅读 [README](../README.md)。
