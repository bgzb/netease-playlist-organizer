喜欢的歌越来越多，想找出其中的日语摇滚、慢节奏民谣，或某几位歌手的作品？网易云歌单整理可以在 Mac 网易云客户端里读取收藏，按条件筛选、预览，再将选中的歌曲整理到新歌单或已有歌单中。

**原收藏保留。** 整理只向目标歌单追加歌曲，不删除或重排「我喜欢的音乐」。普通使用无需安装 Node.js、Python，也无需配置 API Key。

## 本地开发中的任意歌单升级

当前源码在已发布 1.0.0 界面与图标基础上新增单来源扫描：默认我喜欢，也可从创建/收藏列表、扫描历史选择，或输入歌单 ID / 完整分享链接读取他人的可访问歌单。选择后先展示该来源缓存，手动继续或强制更新；短链接需先打开并复制完整链接/ID。无权限或列表不完整会提示并保留缓存。

扫描缓存按账号和歌单分别保存，兼容迁移旧缓存；支持清除全部或仅非我喜欢歌单缓存，保留写入恢复日志。切换来源先暂停并保存，保存失败停留当前来源；写入仍仅面向本人可写目标。四步工作区、主题、候选分页、右下角入口及图标保留。

筛选页支持将条件命名为方案，按账号保存、跨歌单套用，并可重命名或删除。方案只保存条件；套用会重置人工选歌，并使旧的写入确认失效。来源区的“管理扫描缓存”逐个显示歌单进度、保存时间和估算占用，支持单独删除；清理缓存会保留筛选方案及写入日志。

这是尚未发布的本地构建 6；下方 v1.0.0 下载链接仍指向原正式发布。

## 可以做什么

- **按四个维度筛选**：组合曲风、语种、歌手和 BPM，找到适合当前心情或场景的音乐。
- **先预览，再决定**：查看歌曲详情，手动加入或排除歌曲；数据缺失的歌曲单独列出，方便检查。
- **整理到你选择的歌单**：新建私密歌单，或选择自己已有的可写歌单；写入前再次审阅清单与目标。
- **边整理，边听歌**：扫描显示实际进度，支持暂停与收起。收起后，右下角入口继续显示状态，完成时不打断当前操作。
- **写完再核对**：分批追加并读回检查；结果不确定时提供恢复核对入口，避免直接重复创建歌单。
- **继续调整同一批收藏**：整理完成后可打开目标歌单，也可回到筛选页，继续组合下一份歌单。

## 下载与安装

### 1. 确认兼容性

| 项目 | 支持范围 |
| --- | --- |
| Mac 芯片 | Apple Silicon（M 系列），暂不支持 Intel |
| 系统 | macOS 13 及以上；尚未全面验证各系统版本 |
| 网易云音乐 | Mac 客户端 **3.1.1 / build 3019** |

目前在一台 Apple Silicon Mac 上完成验证，其他客户端版本尚未验证。使用前请先核对自己的客户端版本。

### 2. 下载应用

前往 **[v1.0.0 发布页](https://github.com/bgzb/netease-playlist-organizer/releases/tag/v1.0.0)**，在附件中下载 **「网易云歌单整理应用.zip」**，也可以点击上方「下载 Mac 应用」直接下载。

应用附件文件名为 `netease-playlist-organizer-1.0.0-macos-arm64.zip`；「网易云歌单整理源码.zip」的文件名为 `netease-playlist-organizer-1.0.0-source.zip`。源码 ZIP 与 GitHub 自动提供的 Source code 面向开发者，普通使用请选择应用 ZIP。发布附件还提供 `SHA256SUMS.txt`，用于校验下载文件。

### 3. 解压并安装

双击 ZIP 解压，将 **「网易云歌单整理.app」** 移入个人应用目录 `~/Applications`；目录不存在时可以创建。以后更新时替换这里的旧应用，只保留一个安装入口。

### 4. 首次打开

打开「网易云歌单整理」。应用会尝试连接网易云并加载面板；如果需要重新打开网易云，会先询问你，确认后可能中断当前播放。未出现面板时，可在工具控制窗口点击「打开整理面板」。

应用目前采用 **ad-hoc 签名，尚未通过 Apple 公证**。首次打开可能遇到系统安全提示，请在确认下载来源后按 [安装帮助](docs/INSTALL.md)操作；无需关闭系统安全保护。

## 第一次整理

1. **准备收藏**：点击「开始整理」，读取并核对完整收藏，随后扫描歌曲元数据。期间可以暂停或收起面板。
2. **筛选歌曲**：选择曲风、语种、歌手或 BPM 范围，查看匹配结果，并勾选调整。不同维度同时满足，同一维度中的多个选项满足其一即可；想整理全部收藏时，需明确选择「全部收藏」。
3. **选择去处**：新建私密歌单，或选择自己已有的可写歌单。
4. **审阅并确认**：检查完整入选清单、目标和隐私设置，再确认写入。清单分页只影响显示，不限制实际入选数量。
5. **查看结果**：等待写入与核对完成，点击「打开目标歌单」查看；点击「结束整理」可回到筛选页，继续整理其他组合。

如果提示「等待核对」或操作结果不确定，请使用面板提供的恢复核对流程，再重新审阅。不要因为暂时未看到结果就重复创建。

## 常见问题

**会修改或删除我原来的收藏吗？**

不会删除或重排原收藏。已有目标歌单只追加尚未包含的歌曲。

**为什么有些歌曲无法判断？**

曲风、语种或 BPM 等信息可能缺失。工具会将这些歌曲单独列出，你可以查看详情并手动加入。网络、权限或限流也可能使扫描暂停，按面板提示处理后继续。

**收起后从哪里打开？**

点击网易云窗口右下角、播放器上方的「歌单整理」按钮。工作区展开时会隐藏这个浮动入口，使用面板右上角的「收起」返回。

**升级后为什么还是旧界面？**

已加载的面板会保留原实例。请等待当前任务结束，在工具控制窗口选择「移除面板」，再点击「打开整理面板」加载新版。

**如何结束使用或卸载？**

在工具控制窗口选择「恢复普通启动」并确认，等待网易云重新以普通方式打开，再退出工具。重开可能中断播放。若要卸载，随后删除应用即可；关闭控制窗口、移除面板或退出工具本身，都不会关闭网易云的调试监听。

**遇到连接失败怎么办？**

确认客户端版本在支持范围内，再从工具控制窗口手动重试。冷启动断连曾在前期出现，后续功能验证未再复现，但尚未证明所有环境均不会发生。

## 数据与隐私

工具使用本机网易云客户端已有能力读取收藏和写入歌单，不要求你粘贴密码、Cookie 或其他凭据，也不提供单独的数据上传服务。歌曲信息读取和歌单操作仍需要网易云服务正常可用。

扫描缓存、检查点和写入恢复记录保存在本机网易云页面中，并按账号隔离。普通筛选和人工选择不跨重启保存；恢复记录不会自动恢复一次写入确认。来源区提供“清除全部扫描缓存”和“清除非我喜欢歌单缓存”，均只清理当前账号的工具扫描数据，保留写入恢复日志和真实歌单。

本项目与网易云无隶属关系。提交问题时，请勿附带账号、Cookie、完整歌曲清单或原始接口响应。

<summary>源码构建、测试与维护说明</summary>

构建需要 Apple Silicon Mac、Node.js 24 LTS（见 `.nvmrc`）和 Swift 6。原生测试需要 macOS 14+ 与匹配的 Testing.framework，应用部署下限仍为 macOS 13。

```bash
npm ci --cache ./work/npm-cache --registry=https://registry.npmjs.org
npm run verify:offline
bash scripts/swift-local.sh test --package-path launcher
npm run build:panel
bash scripts/build-app.sh
# 源码包只包含干净已提交 HEAD
bash scripts/package-source.sh
```

`verify:offline` 包含类型检查、合成 TS/JS 测试和实际面板入口冒烟；原生测试使用合成传输及进程状态，不启动真实客户端。GitHub Actions 结果请查看对应提交，合成验证不能代替所有账号和客户端环境的实际验证。

产物位于 `work/dist/`。打包会将 `assets/app-icon.png` 转换为 16–1024 像素 ICNS，并校验 ZIP 解压后的签名、arm64 架构和资源；保留用于分发的 ZIP，清理临时裸应用。Swift 辅助脚本只在 `work/` 复制公开工具链接口，不修改系统工具链。

本地合成界面预览：`npm run preview:panel`。合成扫描基准：`npm run benchmark:scan`，其计时不代表真实网络性能。维护者只读探针 `npm run verify:read` 需要已由启动器连接的受支持客户端，日常构建和 CI 不运行此命令。

`npm run export:public -- public-clean` 可将干净提交源码导出至新的 `work/public-clean/`，不携带 Git 历史。Git 和源码包只保留源码、资源、测试、构建配置与必要公开文档；设计、实施计划、接入验证、截图和发布验收记录保留本地，不纳入提交。

启动失败的本机临时诊断文件为 `ncm-organizer-v1-diagnostics/startup-failure.ndjson`，只记录固定类别与阶段，最大 16 KiB，不记录账号、歌曲或凭据。可用 `getconf DARWIN_USER_TEMP_DIR` 定位临时目录。运行期间客户端使用回环调试端口 19319；工具不修改或重新签名网易云应用，不修改系统保护或注册开机启动。
